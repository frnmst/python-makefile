# Security Policy

## Supported Versions

The latest
[GIT tagged version of python-makefile](https://github.com/frnmst/python-makefile/tags) is the
only one supported. When a new version is released, that one will be the only
one supported.

## Reporting a Vulnerability

Send me an [email](mailto:solvecomputersciencecollabs+SECURITY-python-makefile@gmail.com?subject=report%20python-makefile%20vulnerability&body=Please%20encrypt%20before%20sending), preferably encryped.
